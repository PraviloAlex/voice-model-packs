Kukuluku Voice는 인터넷 없이 작동해요. 음성은 컴퓨터에서 바로 인식되고 번역돼요.

  • 계정 없음
  • 광고 없음
  • 추적 없음
01

프로그램이 항상 제 말을 듣나요?

아니요. 받아쓰는 동안만 들어요. 기본값은 Ctrl+Win을 누르고 있는 동안이에요.자세히 ›접기

F9(음성으로 삽입)를 누를 때와 마이크를 테스트할 때도 마이크가 켜져요. 소리는 컴퓨터에 있는 모델이 인식하고, 임시 오디오 파일은 바로 삭제돼요. 녹음은 ‘Save audio recordings’를 켠 경우에만 남아요(기본값은 꺼짐).

02

제가 말한 내용은 어디로 가나요?

커서가 있는 창과 디스크에 있는 기록(History)으로 가요.자세히 ›접기

보통 텍스트는 클립보드를 거쳐 입력되고, 2초 뒤 원래 내용이 돌아와요. 받아쓴 내용은 앱이 비밀번호 관리자처럼 표시해 두기 때문에 Windows 클립보드 기록(Win+V)과 클라우드에 남지 않아요. 기록 끄기·지우기는 앱의 ‘Settings → Privacy’에서 해요.

03

번역은 인터넷을 쓰나요?

아니요. 컴퓨터에 있는 모델이 번역해요.자세히 ›접기

선택한 텍스트를 가져오기 위해 프로그램이 클립보드로 잠깐 복사한 뒤 바로 원래대로 돌려놔요. 이건 일반 복사라서, 클립보드 기록(Win+V)이 켜져 있으면 Ctrl+C를 누른 것처럼 선택한 내용이 기록에 남아요. 언어 쌍은 한 번만 내려받아요.

04

프로그램은 다른 프로그램에 대해 무엇을 아나요?

텍스트를 넣는 프로그램의 이름만 알아요. 입력란 내용은 ‘Notice my corrections’를 켠 경우에만 읽어요.자세히 ›접기

이름으로 삽입 방식을 골라요. ‘Notice my corrections’는 켜기 전까지 꺼져 있어요. 켜면 받아쓰기 후 텍스트를 넣은 입력란을 읽어서 고친 내용을 기억해요. 창 제목, 비밀번호 입력란, 다른 프로그램의 파일은 읽지 않아요.

05

디스크에는 무엇이 저장되나요?

기록(History), 사전(Dictionary), 텍스트 조각, 설정, 그리고 켠 경우 녹음. 모두 Windows 사용자 프로필 안의 일반 파일이에요.자세히 ›접기

기록은 처음부터 켜져 있고 끌 수 있어요. 작동 로그도 있지만 받아쓴 내용은 들어 있지 않아요. 모두 컴퓨터 안에 남아요.

06

프로그램은 언제 인터넷에 연결되나요?

음성 모델이나 번역 모델을 내려받을 때만요.자세히 ›접기

모델은 GitHub에 있고, 프로그램은 각 파일이 빠짐없이, 바뀌지 않고 도착했는지 확인해요. GitHub는 다른 다운로드와 마찬가지로 컴퓨터 주소와 파일 이름을 볼 수 있어요. 저희에게는 아무것도 오지 않아요.

07

프로그램이 고장 나면요?

프로그램 자체는 아무것도 보내지 않아요. 이메일은 직접 보낼 때만 나가요.자세히 ›접기

‘Report a problem’은 로그를 압축 파일로 묶고 이메일을 열어요. 압축 파일은 직접 첨부해 주세요. 이메일은 최대 12개월 보관하며, 답장과 프로그램 수정에만 읽어요. 이메일을 보내면 Gmail(미국)에 보관되는 데 동의하는 거예요.

08

모두 지우려면요?

프로그램을 제거하면 Windows가 기록, 사전, 모델과 함께 지워요(직접 고른 모델 폴더는 제외).자세히 ›접기

Windows에서 ‘설정 → 앱 → 설치된 앱 → Kukuluku Voice → 제거’. 직접 고른 모델 폴더는 손으로 지워 주세요. 기록만 지우려면 앱의 ‘Settings → Privacy → Clear history’.

09

개인 데이터 수집

누구에게서도 데이터를 수집하지 않아요. 아이들도 마찬가지예요. 저희에게 오는 건 직접 쓴 이메일뿐이에요.

10

책임자는 누구이고, 저는 무엇을 할 수 있나요?

Kukuluku 개발자, 아르헨티나, kukuluku.app@gmail.com.자세히 ›접기

이 방침은 Microsoft Store 버전에 적용돼요. 저희가 가진 정보(사실상 이메일뿐)를 확인·정정·삭제하고 싶으면 이메일을 보내 주세요. 10일 안에 답해요. 거주 국가의 개인정보 보호 기관에 민원을 낼 수도 있어요.

11

컴퓨터 밖으로 나가는 것

  • 모델 파일 요청 → GitHub, 음성·번역 모델을 내려받을 때
  • 프로그램 업데이트 → Microsoft Store, 다른 Store 앱과 같음
  • ‘Report a problem’ 이메일 → Gmail(Google, 미국), 직접 보낼 때만
  • 프로그램은 그 밖에 아무것도 보내지 않아요.
