Kukuluku Voice 无需联网即可使用。语音直接在你的电脑上识别和翻译。

  • 无需账号
  • 没有广告
  • 没有跟踪
01

程序会一直在听我说话吗？

不会。只在你听写时：默认是按住 Ctrl+Win 期间。详细 ›收起

按 F9（用语音插入）和测试麦克风时，麦克风也会打开。声音由你电脑上的模型识别，临时音频文件会立即删除。只有你开启了“保存音频录音”（默认关闭），录音才会保留。

02

我说的话去哪儿了？

进入光标所在的窗口，以及你磁盘上的历史记录。详细 ›收起

文本通常通过剪贴板插入，2 秒后剪贴板恢复原来的内容。听写的文本不会进入 Windows 剪贴板历史（Win+V），也不会上传到云：程序会像密码管理器那样给它加上标记。关闭或清除历史：在程序中打开“设置 → 隐私”。

03

翻译会上网吗？

不会。由电脑上的模型翻译。详细 ›收起

为了获取选中的文本，程序会通过剪贴板瞬间复制它，并立即把剪贴板恢复原样。这是普通的复制：如果开启了剪贴板历史（Win+V），选中的文本会像按 Ctrl+C 后一样出现在那里。语言对只需下载一次。

04

程序对其他程序了解什么？

只知道插入文本的程序名称。文本框的内容：仅当你开启了“留意我的更正”。详细 ›收起

程序根据名称选择插入方式。“留意我的更正”默认关闭；开启后，程序会在听写后读取插入文本的字段，以记住你的更正。它不会读取窗口标题、密码框和其他程序的文件。

05

我的磁盘上存了什么？

历史记录、词典、文本片段、设置，以及你开启后的音频录音：都是你 Windows 用户目录里的普通文件。详细 ›收起

历史记录默认开启，可以关闭。还有运行日志，其中不含你听写的内容。这些都留在你的电脑上。

06

程序什么时候联网？

只在下载语音或翻译模型时。详细 ›收起

模型存放在 GitHub 上，程序会检查每个文件是否完整、未被篡改。GitHub 能看到你电脑的地址和文件名，和任何下载一样；我们收不到任何东西。

07

程序出问题怎么办？

程序本身不发送任何东西：只有你自己发送，邮件才会发出。详细 ›收起

“报告问题”会把日志打包成压缩文件并打开一封邮件，压缩文件由你自己附上。邮件最多保存 12 个月；我们阅读邮件只为回复你和修复程序。发送邮件即表示你同意邮件保存在 Gmail（美国）。

08

怎样删除一切？

卸载程序：Windows 会把它连同历史记录、词典和模型一起删除（你自己选择的模型文件夹除外）。详细 ›收起

在 Windows 中：“设置 → 应用 → 已安装的应用 → Kukuluku Voice → 卸载”。你自己的模型文件夹请手动删除。只清除历史记录：在程序中“设置 → 隐私 → 清除历史”。

09

个人数据收集

我们不向任何人收集数据，包括儿童：只有你自己写信时，邮件才会到达我们。

10

谁负责？我能做什么？

Kukuluku 开发者，阿根廷，kukuluku.app@gmail.com。详细 ›收起

本政策适用于 Microsoft Store 版本。写信给我们，即可了解、更正或删除我们掌握的关于你的信息（实际上只有你的邮件），我们会在 10 天内答复。你可以向本国的数据保护机构投诉。

11

哪些内容会离开你的电脑

  • 模型文件请求 → GitHub, 下载语音或翻译模型时
  • 程序更新 → Microsoft Store, 与任何 Store 应用相同
  • “报告问题”邮件 → Gmail（Google，美国）, 仅当你自己发送时
  • 程序不会发送其他任何内容。
