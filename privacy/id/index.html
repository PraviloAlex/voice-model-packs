Kukuluku Voice bekerja tanpa internet. Ucapan dikenali dan diterjemahkan langsung di komputermu.

  • Tanpa akun
  • Tanpa iklan
  • Tanpa pelacakan
01

Apakah aplikasi mendengarkan saya terus?

Tidak. Hanya saat kamu mendikte - secara bawaan, selama kamu menahan Ctrl+Win.Selengkapnya ›Tutup

Mikrofon juga menyala saat kamu menekan F9 (sisipkan dengan suara) dan saat kamu mengujinya. Suara dikenali oleh model di komputermu; file audio sementara langsung dihapus. Rekaman hanya disimpan jika kamu menyalakan “Save audio recordings” (bawaannya mati).

02

Ke mana perginya yang saya ucapkan?

Ke jendela tempat kursor berada, dan ke Riwayat (History) di disk komputermu.Selengkapnya ›Tutup

Biasanya teks dimasukkan lewat clipboard, dan setelah 2 detik teks sebelumnya kembali. Jika di Windows riwayat clipboard (Win+V) atau sinkronisasinya menyala, Windows bisa menyimpan hasil dikte dan mengirimnya ke cloud Microsoft. Untuk mematikan atau menghapus Riwayat: di aplikasi, “Settings → Privacy”.

03

Apakah terjemahan masuk ke internet?

Tidak. Model di komputer yang menerjemahkan.Selengkapnya ›Tutup

Untuk mengambil teks yang dipilih, aplikasi menyalinnya sebentar lewat clipboard lalu langsung mengembalikan clipboard seperti semula. Pasangan bahasa hanya diunduh sekali.

04

Apa yang diketahui aplikasi tentang aplikasi lain?

Hanya nama aplikasi tempat teks disisipkan. Isi kolom teks hanya jika kamu menyalakan “Notice my corrections”.Selengkapnya ›Tutup

Dari nama itu, aplikasi memilih cara menyisipkan. “Notice my corrections” mati sampai kamu menyalakannya: setelah itu, sesudah mendikte, aplikasi membaca kolom tempat teks disisipkan untuk mengingat koreksimu. Aplikasi tidak membaca judul jendela, kolom kata sandi, atau file aplikasi lain.

05

Apa saja yang ada di disk saya?

Riwayat, Kamus, potongan teks, pengaturan, dan rekaman audio jika kamu menyalakannya - semuanya file biasa di profil Windows kamu.Selengkapnya ›Tutup

Riwayat menyala sejak awal; kamu bisa mematikannya. Ada juga log kerja - tanpa isi yang kamu dikte. Semuanya tetap di komputermu.

06

Kapan aplikasi tersambung ke internet?

Hanya untuk mengunduh model ucapan atau terjemahan.Selengkapnya ›Tutup

Model disimpan di GitHub, dan aplikasi memeriksa bahwa setiap file tiba utuh dan tidak diubah. GitHub melihat alamat komputermu dan nama file, seperti pada setiap unduhan; kami tidak menerima apa pun. Jika GitHub tidak bisa diakses, model Whisper bisa diunduh dari situs cadangan Hugging Face - di sana aplikasi tidak memeriksa file.

07

Bagaimana jika aplikasi bermasalah?

Aplikasi sendiri tidak mengirim apa pun: email hanya terkirim jika kamu mengirimnya.Selengkapnya ›Tutup

“Report a problem” mengumpulkan log ke dalam arsip dan membuka email - arsipnya kamu lampirkan sendiri. Email disimpan paling lama 12 bulan; kami membacanya hanya untuk membalasmu dan memperbaiki aplikasi. Dengan mengirim email, kamu setuju email itu disimpan di Gmail (AS).

08

Bagaimana cara menghapus semuanya?

Copot pemasangan aplikasi - Windows menghapusnya bersama Riwayat, Kamus, dan model (kecuali folder model yang kamu pilih sendiri).Selengkapnya ›Tutup

Di Windows: “Pengaturan → Aplikasi → Aplikasi yang diinstal → Kukuluku Voice → Copot pemasangan”. Hapus folder modelmu sendiri secara manual. Hanya Riwayat: di aplikasi, “Settings → Privacy → Clear history”.

09

Pengumpulan data pribadi

Kami tidak mengumpulkan data dari siapa pun, termasuk anak‑anak: yang sampai ke kami hanya email, jika kamu menulisnya sendiri.

10

Siapa yang bertanggung jawab, dan apa yang bisa saya lakukan?

Pengembang Kukuluku, Argentina, kukuluku.app@gmail.com.Selengkapnya ›Tutup

Kebijakan ini berlaku untuk versi Microsoft Store. Tulis ke kami untuk mengetahui, memperbaiki, atau menghapus data kami tentang kamu (pada praktiknya hanya emailmu) - kami membalas dalam 10 hari. Kamu bisa mengadu ke otoritas perlindungan data di negaramu.

11

Apa yang keluar dari komputermu

  • Permintaan file model → GitHub, saat model ucapan atau terjemahan diunduh
  • Sumber cadangan model Whisper → Hugging Face, hanya jika GitHub tidak bisa diakses
  • Pembaruan aplikasi → Microsoft Store, seperti aplikasi Store lainnya
  • Email “Report a problem” → Gmail (Google, AS), hanya jika kamu mengirimnya sendiri
  • Selain itu, aplikasi tidak mengirim apa pun.
