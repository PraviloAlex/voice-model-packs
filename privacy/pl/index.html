Kukuluku Voice działa bez internetu. Mowa jest rozpoznawana i tłumaczona bezpośrednio na twoim komputerze.

  • Bez konta
  • Bez reklam
  • Bez śledzenia
01

Czy program słyszy mnie cały czas?

Nie. Tylko gdy dyktujesz - domyślnie, dopóki trzymasz Ctrl+Win.Więcej ›Zwiń

Mikrofon włącza się też po F9 (wstawianie głosem) i gdy go sprawdzasz. Dźwięk rozpoznaje model na twoim komputerze; tymczasowy plik dźwiękowy jest od razu usuwany. Nagrania zostają tylko wtedy, gdy włączysz „Zapisuj nagrania audio” (domyślnie wyłączone).

02

Dokąd trafia to, co mówię?

Do okna, w którym stoi kursor, i do Historii na twoim dysku.Więcej ›Zwiń

Zwykle tekst trafia przez schowek, a po 2 sekundach wraca poprzedni tekst. Jeśli w Windows włączona jest historia schowka (Win+V) lub jej synchronizacja, Windows może zapisać dyktowanie i wysłać je do chmury Microsoft. Wyłączyć lub wyczyścić Historię: w aplikacji „Ustawienia → Prywatność”.

03

Czy tłumaczenie idzie do internetu?

Nie. Tłumaczy model na komputerze.Więcej ›Zwiń

Aby wziąć zaznaczony tekst, program na chwilę kopiuje go przez schowek i od razu przywraca schowek. Pary języków pobierają się raz.

04

Co program wie o innych programach?

Tylko nazwę programu, do którego wstawia tekst. Pole z tekstem - tylko jeśli włączysz „Zauważaj moje poprawki”.Więcej ›Zwiń

Po nazwie dobiera sposób wstawiania. „Zauważaj moje poprawki” jest wyłączone, dopóki go nie włączysz: wtedy po dyktowaniu program czyta pole, do którego wstawił tekst, by zapamiętać twoje poprawki. Nie czyta tytułów okien, pól haseł ani plików innych programów.

05

Co leży na moim dysku?

Historia, Słownik, wstawki tekstu, ustawienia i nagrania audio, jeśli je włączysz - zwykłe pliki w twoim profilu Windows.Więcej ›Zwiń

Historia jest włączona od początku; możesz ją wyłączyć. Są tam też dzienniki pracy - bez treści dyktowania. Wszystko zostaje na komputerze.

06

Kiedy program łączy się z internetem?

Tylko aby pobrać model mowy lub tłumaczenia.Więcej ›Zwiń

Modele są na GitHubie, a program sprawdza, czy każdy plik dotarł cały i niezmieniony. GitHub widzi adres komputera i nazwę pliku, jak przy każdym pobieraniu; do nas nic nie trafia. Jeśli GitHub jest niedostępny, model Whisper może pobrać się z zapasowej strony Hugging Face - tam program nie sprawdza pliku.

07

A jeśli program się zepsuje?

Sam program nic nie wysyła: e‑mail wychodzi tylko wtedy, gdy go wyślesz.Więcej ›Zwiń

„Zgłoś problem” pakuje dzienniki do archiwum i otwiera e‑mail - archiwum dołączasz sam. E‑maile przechowujemy do 12 miesięcy; czytamy je tylko po to, by odpowiedzieć i naprawić program. Wysyłając e‑mail, zgadzasz się, że jest przechowywany w Gmailu (USA).

08

Jak usunąć wszystko?

Odinstaluj program - Windows usunie go razem z Historią, Słownikiem i modelami (poza folderem modeli wybranym przez ciebie).Więcej ›Zwiń

W Windows: „Ustawienia → Aplikacje → Zainstalowane aplikacje → Kukuluku Voice → Odinstaluj”. Własny folder modeli usuń ręcznie. Tylko Historię: w aplikacji „Ustawienia → Prywatność → Wyczyść historię”.

09

Zbieranie danych osobowych

Nie zbieramy danych od nikogo, także od dzieci: dociera do nas tylko e‑mail, jeśli sam do nas napiszesz.

10

Kto odpowiada i co mogę zrobić?

Twórca Kukuluku, Argentyna, kukuluku.app@gmail.com.Więcej ›Zwiń

Polityka dotyczy wersji z Microsoft Store. Napisz do nas, aby dowiedzieć się, poprawić lub usunąć to, co mamy o tobie (w praktyce tylko twoje e‑maile) - odpowiemy w ciągu 10 dni. Skargę możesz złożyć do organu ochrony danych w swoim kraju.

11

Co opuszcza twój komputer

  • Zapytanie o plik modelu → GitHub, gdy pobiera się model mowy lub tłumaczenia
  • Zapasowe źródło modelu Whisper → Hugging Face, tylko gdy GitHub jest niedostępny
  • Aktualizacje programu → Microsoft Store, jak w każdej aplikacji ze Store
  • E‑mail „Zgłoś problem” → Gmail (Google, USA), tylko jeśli sam go wyślesz
  • Nic więcej program nie wysyła.
