O Kukuluku Voice funciona sem internet. A fala é reconhecida e traduzida direto no seu computador.

  • Sem conta
  • Sem anúncios
  • Sem rastreamento
01

O programa me ouve o tempo todo?

Não. Só enquanto você dita - por padrão, enquanto segura Ctrl+Win.Mais ›Menos

O microfone também liga com F9 (inserir por voz) e quando você o testa. Um modelo no seu computador reconhece o som; o arquivo de áudio temporário é apagado na hora. As gravações ficam só se você ativou “Salvar gravações de áudio” (desativado por padrão).

02

Para onde vai o que eu digo?

Para a janela onde está o cursor e para o Histórico no seu disco.Mais ›Menos

Normalmente o texto entra pela área de transferência, e depois de 2 segundos o texto anterior volta. Se no Windows estiverem ativados o histórico da área de transferência (Win+V) ou a sincronização dele, o Windows pode guardar um ditado e enviá-lo para a nuvem da Microsoft. Para desativar ou limpar o Histórico: no app, “Configurações → Privacidade”.

03

A tradução vai para a internet?

Não. Quem traduz é um modelo no computador.Mais ›Menos

Para pegar o texto selecionado, o programa o copia por um instante pela área de transferência e a devolve como estava. Os pares de idiomas são baixados uma vez só.

04

O que o programa sabe sobre outros programas?

Só o nome do programa onde insere o texto. O campo de texto, só se você ativou “Perceber minhas correções”.Mais ›Menos

Pelo nome, ele escolhe como inserir. “Perceber minhas correções” fica desligado até você ativar: aí, depois de um ditado, o programa lê o campo onde inseriu o texto para aprender suas correções. Ele não lê títulos de janelas, campos de senha nem arquivos de outros programas.

05

O que fica no meu disco?

Histórico, Dicionário, trechos de texto, configurações e gravações de áudio, se você as ativou - arquivos comuns no seu perfil do Windows.Mais ›Menos

O Histórico vem ativado e você pode desativá-lo. Também há registros de funcionamento, sem o que você ditou. Tudo fica no seu computador.

06

Quando o programa se conecta à internet?

Só para baixar um modelo de fala ou de tradução.Mais ›Menos

Os modelos ficam no GitHub, e o programa verifica se cada arquivo chegou inteiro e sem alterações. O GitHub vê o endereço do seu computador e o nome do arquivo, como em qualquer download; nada chega até nós. Se o GitHub estiver fora do ar, um modelo Whisper pode ser baixado do site reserva Hugging Face - lá o programa não verifica o arquivo.

07

E se o programa der problema?

O programa em si não envia nada: um e‑mail só sai se você enviá-lo.Mais ›Menos

“Relatar um problema” junta os registros em um arquivo compactado e abre um e‑mail - você mesmo anexa o arquivo. Os e‑mails ficam guardados por até 12 meses; nós os lemos só para responder e consertar o programa. Ao enviar um e‑mail, você concorda que ele fique guardado no Gmail (EUA).

08

Como apago tudo?

Desinstale o programa - o Windows o apaga junto com o Histórico, o Dicionário e os modelos (menos uma pasta de modelos escolhida por você).Mais ›Menos

No Windows: “Configurações → Aplicativos → Aplicativos instalados → Kukuluku Voice → Desinstalar”. Apague à mão sua própria pasta de modelos. Só o Histórico: no app, “Configurações → Privacidade → Limpar histórico”.

09

Coleta de dados pessoais

Não coletamos dados de ninguém, nem de crianças: só chega até nós um e‑mail, se você mesmo escrever.

10

Quem é o responsável e o que posso fazer?

O desenvolvedor do Kukuluku, Argentina, kukuluku.app@gmail.com.Mais ›Menos

Esta política vale para a versão da Microsoft Store. Escreva para nós para saber, corrigir ou apagar o que temos sobre você (na prática, só seus e‑mails) - respondemos em até 10 dias. Você pode reclamar à autoridade de proteção de dados do seu país.

11

O que sai do seu computador

  • Pedido de um arquivo de modelo → GitHub, quando um modelo de fala ou de tradução é baixado
  • Fonte reserva de um modelo Whisper → Hugging Face, só se o GitHub estiver fora do ar
  • Atualizações do programa → Microsoft Store, como em qualquer app da Store
  • E‑mail de “Relatar um problema” → Gmail (Google, EUA), só se você mesmo enviar
  • O programa não envia mais nada.
