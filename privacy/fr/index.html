Kukuluku Voice fonctionne sans Internet. La voix est reconnue et traduite directement sur ton ordinateur.

  • Sans compte
  • Sans publicité
  • Sans pistage
01

Le programme m’écoute-t-il tout le temps ?

Non. Seulement pendant que tu dictes - par défaut, tant que tu maintiens Ctrl+Win.Détails ›Réduire

Le micro s’allume aussi avec F9 (insertion vocale) et quand tu le testes. Un modèle sur ton ordinateur reconnaît le son ; le fichier audio temporaire est supprimé aussitôt. Les enregistrements ne sont gardés que si tu as activé « Enregistrer les audios » (désactivé par défaut).

02

Où va ce que je dis ?

Dans la fenêtre où se trouve le curseur, et dans l’Historique sur ton disque.Détails ›Réduire

D’habitude, le texte passe par le presse-papiers, et au bout de 2 secondes le texte précédent revient. Si l’historique du presse-papiers de Windows (Win+V) ou sa synchronisation est activé, Windows peut garder une dictée et l’envoyer dans le cloud de Microsoft. Pour désactiver ou effacer l’Historique : dans l’app, « Paramètres → Confidentialité ».

03

La traduction passe-t-elle par Internet ?

Non. C’est un modèle sur l’ordinateur qui traduit.Détails ›Réduire

Pour prendre le texte sélectionné, le programme le copie un instant via le presse-papiers, puis le remet aussitôt comme il était. Les paires de langues se téléchargent une seule fois.

04

Que sait le programme des autres programmes ?

Seulement le nom du programme où il insère le texte. Le champ de texte, seulement si tu as activé « Remarquer mes corrections ».Détails ›Réduire

Avec ce nom, il choisit comment insérer. « Remarquer mes corrections » est désactivé tant que tu ne l’actives pas : alors, après une dictée, le programme lit le champ où il a inséré le texte pour retenir tes corrections. Il ne lit pas les titres de fenêtres, les champs de mot de passe ni les fichiers des autres programmes.

05

Qu’y a-t-il sur mon disque ?

Historique, Dictionnaire, extraits de texte, paramètres et enregistrements audio si tu les as activés : de simples fichiers dans ton profil Windows.Détails ›Réduire

L’Historique est activé dès le départ ; tu peux le désactiver. Il y a aussi des journaux de fonctionnement, sans ce que tu as dicté. Tout cela reste sur ton ordinateur.

06

Quand le programme se connecte-t-il à Internet ?

Seulement pour télécharger un modèle de voix ou de traduction.Détails ›Réduire

Les modèles sont sur GitHub, et le programme vérifie que chaque fichier est arrivé entier et non modifié. GitHub voit l’adresse de ton ordinateur et le nom du fichier, comme pour tout téléchargement ; rien ne nous parvient. Si GitHub est inaccessible, un modèle Whisper peut se télécharger depuis le site de secours Hugging Face - là, le programme ne vérifie pas le fichier.

07

Et si le programme plante ?

Le programme lui-même n’envoie rien : un e‑mail ne part que si tu l’envoies.Détails ›Réduire

« Signaler un problème » rassemble les journaux dans une archive et ouvre un e‑mail - c’est toi qui joins l’archive. Les e‑mails sont conservés jusqu’à 12 mois ; nous les lisons seulement pour te répondre et réparer le programme. En envoyant un e‑mail, tu acceptes qu’il soit conservé dans Gmail (États-Unis).

08

Comment tout supprimer ?

Désinstalle le programme - Windows le supprime avec l’Historique, le Dictionnaire et les modèles (sauf un dossier de modèles que tu as choisi toi‑même).Détails ›Réduire

Dans Windows : « Paramètres → Applications → Applications installées → Kukuluku Voice → Désinstaller ». Supprime à la main ton propre dossier de modèles. Pour effacer seulement l’Historique : dans l’app, « Paramètres → Confidentialité → Effacer l’historique ».

09

Collecte de données personnelles

Nous ne collectons de données auprès de personne, enfants compris : seul un e‑mail nous parvient, si tu nous écris.

10

Qui est responsable, et que puis-je faire ?

Le développeur de Kukuluku, Argentine, kukuluku.app@gmail.com.Détails ›Réduire

Cette politique couvre la version du Microsoft Store. Écris-nous pour savoir, corriger ou supprimer ce que nous avons sur toi (en pratique, seulement tes e‑mails) - nous répondons sous 10 jours. Tu peux te plaindre auprès de l’autorité de protection des données de ton pays.

11

Ce qui quitte ton ordinateur

  • Demande d’un fichier de modèle → GitHub, quand un modèle de voix ou de traduction se télécharge
  • Source de secours pour un modèle Whisper → Hugging Face, seulement si GitHub est inaccessible
  • Mises à jour du programme → Microsoft Store, comme pour toute app du Store
  • E‑mail « Signaler un problème » → Gmail (Google, États-Unis), seulement si tu l’envoies toi‑même
  • Le programme n’envoie rien d’autre.
